@lesson c-arr | Πίνακες στη C
@theory
### Μονοδιάστατοι
```c
int a[5];                       /* θέσεις a[0] … a[4] */
int b[5] = {3, 1, 4};           /* τα υπόλοιπα γίνονται 0: {3,1,4,0,0} */
int c[] = {7, 8, 9};            /* μέγεθος 3 από την αρχικοποίηση */
```
- Οι δείκτες ξεκινούν από **0**. Ο τελευταίος είναι **n−1**.
- Η C **δεν** ελέγχει τα όρια. Το `a[5]` σε πίνακα 5 στοιχείων γράφει σε ξένη μνήμη → απρόβλεπτη συμπεριφορά.
- Το μέγεθος πρέπει να είναι σταθερά, π.χ. `#define N 100`. Στη C89 δεν επιτρέπεται μεταβλητή.
- **Δεν** γίνεται ανάθεση πίνακα σε πίνακα (`a = b;` ✗). Αντιγράφεις στοιχείο-στοιχείο.
- Πλήθος στοιχείων: `sizeof(a) / sizeof(a[0])` (μόνο στην εμβέλεια όπου δηλώθηκε ο πίνακας).

### Πίνακες και συναρτήσεις
```c
void print(int a[], int n);      /* ή int *a */
print(a, 5);                     /* περνάμε το όνομα + το μέγεθος */
```
Ο πίνακας περνά ως **διεύθυνση**, άρα η συνάρτηση μπορεί να αλλάξει τα στοιχεία του. Το μέγεθος πρέπει να δοθεί ξεχωριστά.

### Δισδιάστατοι
```c
int m[3][4];                     /* 3 γραμμές, 4 στήλες */
int k[2][3] = {{1,2,3},{4,5,6}};
for (i = 0; i < 3; i++)
    for (j = 0; j < 4; j++)
        m[i][j] = i * j;
```
- Αποθήκευση **κατά γραμμές** (row-major).
- Σε συνάρτηση πρέπει να δοθεί το πλήθος **στηλών**: `void f(int m[][4], int rows)`.

### Τυπικοί αλγόριθμοι
άθροισμα/μέσος όρος, max/min και η θέση τους, σειριακή/δυαδική αναζήτηση, αντιστροφή, μετατόπιση, ταξινόμηση, μέτρηση συχνοτήτων.
@example
**Αντιστροφή πίνακα επί τόπου:**
```c
int a[6] = {1, 2, 3, 4, 5, 6}, i, t;
for (i = 0; i < 6 / 2; i++) {
    t = a[i];
    a[i] = a[6 - 1 - i];
    a[6 - 1 - i] = t;
}
/* a = {6,5,4,3,2,1} */
```
Ο βρόχος πάει **μέχρι τη μέση**. Αν πήγαινε μέχρι το τέλος, θα ξανάκανε τις ανταλλαγές και ο πίνακας θα επέστρεφε στην αρχική του μορφή.

**Θέση του μεγίστου:**
```c
int pos = 0;
for (i = 1; i < n; i++)
    if (a[i] > a[pos]) pos = i;
```
@q mcq
pre: Οι δείκτες πίνακα n στοιχείων πάνε από 0 έως n−1.
q: Για `int a[8];` ποιο είναι το **τελευταίο** έγκυρο στοιχείο;
o: a[8]
o: a[7]
o: a[9]
o: a[1]
a: β
why: Θέσεις 0…7 → **a[7]**.
@q short
pre: Μερική αρχικοποίηση: όσα δεν δόθηκαν γίνονται 0.
q: Με `int b[6] = {5, 2};` πόσο είναι το άθροισμα όλων των στοιχείων του b;
a: 7
why: {5, 2, 0, 0, 0, 0} → **7**.
@q tf
pre: Η C δεν κάνει έλεγχο ορίων.
q: Η C εμφανίζει πάντα μήνυμα σφάλματος όταν γράφουμε σε a[10] ενός πίνακα 10 στοιχείων.
a: Λ
why: **Δεν** ελέγχει όρια. Γράφει σε ξένη μνήμη: μπορεί να μη φανεί τίποτα, να αλλοιωθούν άλλες μεταβλητές ή να καταρρεύσει το πρόγραμμα.
@q short
pre: Ιχνηλάτησε τον βρόχο πάνω στον πίνακα.
q: Τι τυπώνει;
```c
int a[5] = {2, 4, 6, 8, 10}, i, s = 0;
for (i = 0; i < 5; i += 2) s += a[i];
printf("%d", s);
```
a: 18
why: a[0] + a[2] + a[4] = 2 + 6 + 10 = **18**.
@q fill
pre: Σε συνάρτηση με 2Δ πίνακα, ο μεταγλωττιστής πρέπει να ξέρει πόσες στήλες έχει κάθε γραμμή.
q: Για να περάσουμε τον `int m[5][7];` σε συνάρτηση, η παράμετρος γράφεται `int m[][{{7}}]`.
why: Χρειάζεται το πλήθος **στηλών** για τον υπολογισμό των διευθύνσεων (row-major).
@q mcq
pre: Ο πίνακας περνά στη συνάρτηση ως διεύθυνση του πρώτου στοιχείου.
q: Γιατί σχεδόν πάντα περνάμε και το **μέγεθος** μαζί με έναν πίνακα σε συνάρτηση;
o: Γιατί η C το απαιτεί συντακτικά
o: Γιατί η συνάρτηση λαμβάνει μόνο τη διεύθυνση και δεν ξέρει πόσα στοιχεία υπάρχουν
o: Για να αντιγραφεί ο πίνακας
o: Για να ταξινομηθεί
a: β
why: Μέσα στη συνάρτηση το `sizeof(a)` δίνει το μέγεθος **δείκτη**, όχι του πίνακα.
@q short
pre: Δισδιάστατος: m[i][j] με i = γραμμή, j = στήλη.
q: Με `int k[2][3] = {{1,2,3},{4,5,6}};` πόσο είναι το `k[1][0] + k[0][2]`;
a: 7
why: k[1][0] = 4, k[0][2] = 3 → **7**.
@q tf
pre: Η ανάθεση ολόκληρου πίνακα δεν επιτρέπεται.
q: Αν `int a[3], b[3] = {1,2,3};` τότε η εντολή `a = b;` αντιγράφει τον b στον a.
a: Λ
why: **Συντακτικό σφάλμα**: το όνομα πίνακα δεν μπορεί να πάρει νέα τιμή. Αντιγράφεις με βρόχο (ή με memcpy).
@q short
pre: Αντιστροφή επί τόπου: ανταλλάσσεις a[i] με a[n−1−i] μέχρι τη μέση.
q: Πόσες ανταλλαγές κάνει η αντιστροφή επί τόπου πίνακα **9** στοιχείων;
a: 4
why: ⌊9/2⌋ = **4**. Το μεσαίο στοιχείο μένει στη θέση του.
@q mcq
pre: Ο βρόχος συγκρίνει με το τρέχον καλύτερο στοιχείο.
q: Τι υπολογίζει ο κώδικας;
```c
int r = 0;
for (i = 1; i < n; i++) if (a[i] < a[r]) r = i;
```
o: Το μέγιστο στοιχείο
o: Τη θέση του ελαχίστου
o: Το ελάχιστο στοιχείο
o: Τη θέση του μεγίστου
a: β
why: Το r κρατά **δείκτη** (θέση) και αλλάζει όταν βρεθεί μικρότερο → θέση του **ελαχίστου**.
@q short
pre: sizeof πίνακα / sizeof στοιχείου = πλήθος στοιχείων.
q: Με `double d[12];` και sizeof(double) = 8, πόσο είναι το `sizeof(d)`;
a: 96
why: 12 · 8 = **96** bytes.

@lesson c-str | Συμβολοσειρές (strings)
@theory
### Τι είναι
Στη C η συμβολοσειρά είναι **πίνακας χαρακτήρων που τελειώνει με `'\0'`** (μηδενικός χαρακτήρας).
```c
char s[10] = "Γεια";     /* (με ASCII π.χ. "Hi" → 'H','i','\0') */
char t[] = "abc";        /* μέγεθος 4: a b c \0 */
char u[4] = {'a','b','c','\0'};
```
- Για μια λέξη n χαρακτήρων χρειάζεσαι πίνακα **n+1**.
- Το `"a"` (συμβολοσειρά, 2 bytes) ≠ `'a'` (χαρακτήρας, 1 byte).

### Είσοδος/έξοδος
- `printf("%s", s);` και `scanf("%s", s);` — **χωρίς &**, γιατί το όνομα του πίνακα είναι ήδη διεύθυνση. Η scanf σταματά στο **πρώτο κενό**.
- `fgets(s, N, stdin);` διαβάζει ολόκληρη γραμμή μαζί με τα κενά (κρατά και το `'\n'`).
- `getchar()` και `putchar(c)` για μεμονωμένους χαρακτήρες.

### string.h
| Συνάρτηση | Τι κάνει |
|---|---|
| `strlen(s)` | μήκος **χωρίς** το '\0' |
| `strcpy(dst, src)` | αντιγραφή (το `dst = src` **δεν** δουλεύει) |
| `strcat(dst, src)` | προσθήκη στο τέλος |
| `strcmp(a, b)` | 0 αν είναι ίσες, <0 αν a < b, >0 αν a > b (λεξικογραφικά) |
| `strncpy`, `strncmp` | εκδόσεις με όριο n |

Σύγκριση με `==` συγκρίνει **διευθύνσεις**, όχι περιεχόμενο!

### ctype.h
`isalpha`, `isdigit`, `isspace`, `isupper`, `islower`, `toupper`, `tolower`.

### Επεξεργασία χαρακτήρα-χαρακτήρα
```c
for (i = 0; s[i] != '\0'; i++) ...
```
Ψηφίο σε αριθμό: `s[i] - '0'` (π.χ. '7' − '0' = 7).
@example
**Δική μας strlen:**
```c
int my_len(char s[]) {
    int i = 0;
    while (s[i] != '\0') i++;
    return i;
}
```
**Μέτρηση φωνηέντων και κεφαλαία:**
```c
char s[] = "hello world";
int i, v = 0;
for (i = 0; s[i]; i++) {
    if (strchr("aeiou", s[i])) v++;
    s[i] = toupper(s[i]);
}
/* v = 3, s = "HELLO WORLD" */
```
**Σύγκριση:**
- `strcmp("abc", "abd")` < 0 (το 'c' < 'd').
- `strcmp("ab", "abc")` < 0 (το '\0' είναι μικρότερο από το 'c').
@q short
pre: Μια συμβολοσειρά χρειάζεται μία θέση παραπάνω για το '\0'.
q: Πόσα bytes πιάνει ο πίνακας `char t[] = "ΕΑΠ_C";` αν κάθε χαρακτήρας είναι 1 byte (υπέθεσε ASCII-ισοδύναμους χαρακτήρες);

why: 5 χαρακτήρες + '\0' = **6**.
@q mcq
pre: Το strlen μετράει χωρίς τον τερματικό χαρακτήρα.
q: Τι επιστρέφει το `strlen("programming")`;
o: 10
o: 11
o: 12
o: 0
a: β
why: 11 γράμματα· το '\0' **δεν** μετράει.
@q tf
pre: Το == συγκρίνει διευθύνσεις.
q: Για να ελέγξουμε αν δύο συμβολοσειρές s1 και s2 έχουν το ίδιο περιεχόμενο γράφουμε `if (s1 == s2)`.
a: Λ
why: Συγκρίνει **διευθύνσεις** πινάκων. Σωστά: `if (strcmp(s1, s2) == 0)`.
@q fill
pre: Το όνομα πίνακα είναι ήδη διεύθυνση.

@q short

a: 12

@q mcq
pre: strcmp: λεξικογραφική σύγκριση χαρακτήρα-χαρακτήρα.

@lesson c-ptr | Δείκτες
@theory
### Βασικά
Ένας **δείκτης** είναι μεταβλητή που αποθηκεύει μια **διεύθυνση μνήμης**.
```c
int x = 10;
int *p;          /* p: δείκτης σε int */
p = &x;          /* & = διεύθυνση της x */
*p = 20;         /* * = περιεχόμενο της διεύθυνσης → x γίνεται 20 */
```
| Έκφραση | Σημασία |
|---|---|
| `&x` | η διεύθυνση της x |
| `p` | η διεύθυνση που κρατά ο δείκτης |
| `*p` | η τιμή στη θέση που δείχνει ο p (αποαναφορά) |
| `&p` | η διεύθυνση του ίδιου του δείκτη |

- **NULL**: δείκτης που δεν δείχνει πουθενά. Αποαναφορά NULL → κατάρρευση.
- **Μη αρχικοποιημένος** δείκτης δείχνει σε τυχαία θέση → επικίνδυνο.

### Αριθμητική δεικτών
- Το `p + 1` δείχνει στο **επόμενο στοιχείο** του τύπου (μετακίνηση κατά sizeof(τύπου) bytes), όχι στο επόμενο byte.
- `p++`, `p--`.
- Αφαίρεση δύο δεικτών του ίδιου πίνακα = πλήθος στοιχείων ανάμεσά τους.

### Δείκτες και πίνακες
- Το όνομα πίνακα είναι η διεύθυνση του **πρώτου** στοιχείου: `a == &a[0]`.
- `a[i] ≡ *(a + i)` και `&a[i] ≡ a + i`.
- Ένας δείκτης μπορεί να μετακινηθεί (`p++`). Το όνομα πίνακα **δεν** μπορεί (`a++` ✗).

### Προτεραιότητα
- `*p++` → τιμή `*p`, μετά αυξάνεται ο **p** (ο δείκτης).
- `(*p)++` → αυξάνεται η **τιμή** στην οποία δείχνει.
- `++*p` → αυξάνεται η τιμή (και η έκφραση έχει τη νέα τιμή).
@example
```c
int a[4] = {10, 20, 30, 40};
int *p = a;            /* p → a[0] */
printf("%d ", *p);     /* 10 */
p += 2;                /* p → a[2] */
printf("%d ", *p);     /* 30 */
printf("%d ", *(p-1)); /* 20 */
printf("%d ", p - a);  /* 2 */
(*p)++;                /* a[2] = 31 */
printf("%d ", *p++);   /* τυπώνει 31, μετά p → a[3] */
printf("%d", *p);      /* 40 */
```
**Έξοδος:** `10 30 20 2 31 40`
@q mcq
pre: & δίνει διεύθυνση, * δίνει περιεχόμενο.
q: Μετά από `int x = 5, *p = &x; *p = *p + 3;` πόσο είναι το x;
o: 5
o: 3
o: 8
o: η διεύθυνση του x
a: γ
why: Ο p δείχνει στη x· `*p = 5 + 3` → **x = 8**.
@q fill
pre: a[i] και *(a+i) είναι το ίδιο.
q: Για πίνακα a, η έκφραση `*(a + 3)` είναι ισοδύναμη με {{a[3]}}, και η `a + 3` με {{&a[3]}}.
why: Το όνομα του πίνακα είναι η διεύθυνση του a[0]· +3 στοιχεία.
@q short
pre: Αριθμητική δεικτών σε μονάδες στοιχείων.
q: `int a[5] = {3, 6, 9, 12, 15}; int *p = a + 1;` Πόσο είναι το `*(p + 2)`;
a: 12
why: p → a[1]· p+2 → a[3] = **12**.
@q tf
pre: Το p+1 προχωρά κατά ένα στοιχείο, όχι κατά ένα byte.
q: Αν ο p είναι δείκτης σε int (4 bytes) με τιμή 1000, τότε ο p + 1 έχει τιμή 1001.
a: Λ
why: Προχωρά κατά sizeof(int) → **1004**.
@q mcq
pre: Προτεραιότητα: οι μεταθεματικοί τελεστές δένουν πιο σφιχτά από το *.
q: Με `int a[] = {5, 9}; int *p = a;` τι κάνει η εντολή `x = *p++;`
o: x = 6 και ο p μένει στο a[0]
o: x = 5 και ο p μετακινείται στο a[1]
o: x = 9
o: συντακτικό σφάλμα
a: β
why: `*(p++)`: παίρνει το *p = 5 και **μετά** αυξάνει τον δείκτη.
@q short
pre: (*p)++ αυξάνει την τιμή στην οποία δείχνει ο p.
q: `int a[] = {5, 9}; int *p = a; (*p)++; (*p)++;` Πόσο είναι το a[0];
a: 7
why: Αυξάνεται η **τιμή** δύο φορές: 5 → **7**. Ο p μένει στο a[0].
@q tf
pre: Το όνομα του πίνακα είναι σταθερή διεύθυνση.
q: Αν `int a[5];` τότε η εντολή `a++;` είναι έγκυρη.
a: Λ
why: Το όνομα πίνακα **δεν** μπορεί να αλλάξει τιμή. Πρέπει να χρησιμοποιήσεις δείκτη: `int *p = a; p++;`.
@q short
pre: Αφαίρεση δεικτών ίδιου πίνακα = απόσταση σε στοιχεία.
q: `double d[10]; double *p = &d[2], *q = &d[7];` Πόσο είναι το `q - p`;
a: 5
why: 7 − 2 = **5** στοιχεία (όχι 40 bytes).
@q mcq
pre: NULL = «δεν δείχνει πουθενά».
q: Τι συμβαίνει αν εκτελεστεί `*p = 3;` όταν `p == NULL`;
o: Το p γίνεται 3
o: Σφάλμα εκτέλεσης (συνήθως κατάρρευση — segmentation fault)
o: Τίποτα
o: Συντακτικό σφάλμα
a: β
why: Αποαναφορά του NULL → πρόσβαση σε μη επιτρεπτή μνήμη → **κατάρρευση**.
@q short
pre: Ιχνηλάτησε τον δείκτη μέσα στον βρόχο.
q: Τι τυπώνει;
```c
int a[5] = {1, 2, 3, 4, 5}, *p, s = 0;
for (p = a; p < a + 5; p += 2) s += *p;
printf("%d", s);
```
a: 9
why: a[0] + a[2] + a[4] = 1 + 3 + 5 = **9**.
@q fill
pre: Δήλωση δείκτη σε συγκεκριμένο τύπο.
q: Για να δηλώσουμε δείκτη p σε double γράφουμε `double {{*p}};` και για να δείχνει στη μεταβλητή z γράφουμε `p = {{&z}};`
why: Το * στη δήλωση σημαίνει «δείκτης σε».

@lesson c-ref | Πέρασμα με αναφορά και συναρτήσεις με δείκτες
@theory
### Το πρόβλημα
Επειδή στη C όλα περνούν **με τιμή**, το
```c
void swap(int a, int b) { int t = a; a = b; b = t; }
```
**δεν** ανταλλάσσει τίποτα στον καλούντα: ανταλλάσσει αντίγραφα.

### Η λύση: δείκτες
```c
void swap(int *a, int *b) { int t = *a; *a = *b; *b = t; }
...
swap(&x, &y);          /* δίνουμε ΔΙΕΥΘΥΝΣΕΙΣ */
```
Η συνάρτηση γράφει **στις θέσεις μνήμης** των x και y.

### Πολλές «επιστροφές»
```c
void minmax(int a[], int n, int *mn, int *mx) {
    int i;
    *mn = *mx = a[0];
    for (i = 1; i < n; i++) {
        if (a[i] < *mn) *mn = a[i];
        if (a[i] > *mx) *mx = a[i];
    }
}
minmax(v, 10, &lo, &hi);
```

### Κανόνες
- Παράμετρος `int *p` → στην κλήση δίνεις `&x` (ή έναν δείκτη, ή όνομα πίνακα).
- Μέσα στη συνάρτηση γράφεις `*p = …` για να αλλάξεις την αρχική μεταβλητή.
- Το `p = …` (χωρίς *) αλλάζει μόνο το **τοπικό αντίγραφο του δείκτη**.
- **Ποτέ** μην επιστρέφεις διεύθυνση **τοπικής** μεταβλητής: μετά την επιστροφή η μεταβλητή δεν υπάρχει.
- Το `const int *p` δηλώνει ότι η συνάρτηση δεν θα αλλάξει την τιμή στην οποία δείχνει ο p.
@example
```c
void f(int a, int *b) {
    a = a + 10;
    *b = *b + 10;
}
int main(void) {
    int x = 1, y = 1;
    f(x, &y);
    printf("%d %d\n", x, y);   /* 1 11 */
    return 0;
}
```
- Το **a** είναι αντίγραφο του x → το x μένει 1.
- Ο **b** δείχνει στο y → το y γίνεται 11.

**Λάθος που γίνεται συχνά:**
```c
void set(int *p) { int k = 5; p = &k; }   /* ✗ αλλάζει μόνο το τοπικό p */
```
@q mcq
pre: Για να αλλάξει η συνάρτηση μεταβλητές του καλούντος, χρειάζεται τις διευθύνσεις τους.
q: Ποια κλήση της `void swap(int *a, int *b)` είναι **σωστή** για τις int x, y;
o: swap(x, y);
o: swap(&x, &y);
o: swap(*x, *y);
o: swap(&x, y);
a: β
why: Οι παράμετροι είναι δείκτες → δίνεις **διευθύνσεις**.
@q short
pre: Αλλαγή μέσω *p φαίνεται στον καλούντα· αλλαγή απλής παραμέτρου όχι.
q: Τι τυπώνει;
```c
void g(int a, int *b) { a *= 2; *b *= 3; }
int main(void) { int x = 4, y = 4; g(x, &y); printf("%d", x + y); return 0; }
```
a: 16
why: x μένει 4, y = 12 → **16**.
@q tf
pre: Η ανάθεση στον ίδιο τον δείκτη αλλάζει μόνο το τοπικό αντίγραφο.
q: Στη `void h(int *p) { p = NULL; }`, μετά την κλήση `h(q)` ο δείκτης q του καλούντος γίνεται NULL.
a: Λ
why: Ο p είναι **αντίγραφο** του q. Για να αλλάξει ο q χρειάζεται δείκτης σε δείκτη (`int **`).
@q fill
pre: Μέσα στη συνάρτηση, η αποαναφορά γράφει στην αρχική μεταβλητή.
q: Συμπλήρωσε τη συνάρτηση που διπλασιάζει την τιμή του καλούντος: `void dbl(int *p) { {{*p}} = {{*p}} * 2; }`
why: `*p = *p * 2;` (ή `*p *= 2;`).
@q mcq
pre: Οι τοπικές μεταβλητές καταστρέφονται στην επιστροφή.
q: Τι είναι λάθος στη συνάρτηση;
```c

```
o: Τίποτα
o: Επιστρέφει διεύθυνση τοπικής μεταβλητής που δεν θα υπάρχει μετά την επιστροφή
o: Δεν μπορεί να επιστρέψει δείκτη
o: Λείπει το void στην επιστροφή
a: β
why: Ο δείκτης θα είναι **«κρεμάμενος»** (dangling). Λύση: malloc ή static.
@q short
pre: Δύο αποτελέσματα επιστρέφονται μέσω δύο δεικτών.
q: Τι τυπώνει;
```c
void dm(int a, int b, int *q, int *r) { *q = a / b; *r = a % b; }
int main(void) { int q, r; dm(29, 4, &q, &r); printf("%d %d", q, r); return 0; }
```
a: 7 1
why: 29 / 4 = 7, 29 % 4 = 1 → **7 1**.
@q tf
pre: Ένα όνομα πίνακα είναι ήδη διεύθυνση.
q: Όταν περνάμε πίνακα σε συνάρτηση, δεν χρειάζεται & μπροστά από το όνομά του.
a: Σ
why: Το όνομα του πίνακα **είναι** η διεύθυνση του πρώτου στοιχείου.
@q mcq
pre: Το const μπροστά από τον τύπο προστατεύει τα δεδομένα στα οποία δείχνει ο δείκτης.
q: Τι δηλώνει η παράμετρος `const int *p`;
o: Ότι ο δείκτης p δεν μπορεί να αλλάξει
o: Ότι η συνάρτηση δεν μπορεί να αλλάξει την τιμή *p
o: Ότι ο p είναι NULL
o: Ότι ο p δείχνει σε σταθερά #define
a: β
why: Δεδομένα «μόνο για ανάγνωση» μέσω του p. Ο ίδιος ο δείκτης θα ήταν σταθερός με `int *const p`.
@q short
pre: Ιχνηλάτησε τις ανταλλαγές.
q: Με τη σωστή swap με δείκτες: `int a = 1, b = 2, c = 3; swap(&a, &b); swap(&b, &c);` Ποια είναι η τιμή του b;
a: 3
why: Μετά την 1η: a=2, b=1. Μετά τη 2η: b=3, c=1 → **b = 3**.
@q fill
pre: Δείκτης σε δείκτη επιτρέπει σε συνάρτηση να αλλάξει έναν δείκτη του καλούντος.
q: Για να μπορεί μια συνάρτηση να αλλάξει τον `int *head` του καλούντος, η παράμετρος πρέπει να είναι τύπου {{int **}} και η κλήση να δίνει {{&head}}.
why: Χρησιμοποιείται π.χ. στην εισαγωγή στην αρχή μιας λίστας.

@lesson c-struct | Δομές (struct) και typedef
@theory
### Ορισμός δομής
Η **δομή** ομαδοποιεί πεδία **διαφορετικών τύπων** κάτω από ένα όνομα.
```c
struct student {
    int am;
    char name[30];
    double grade;
};                         /* προσοχή στο ; */

struct student s1 = {1021, "Νίκος", 8.5};
```

### Πρόσβαση στα πεδία
- Με μεταβλητή: τελεστής **τελεία** → `s1.grade = 9.0;`
- Με δείκτη: τελεστής **βέλος** → `p->grade` ≡ `(*p).grade`

```c
struct student *p = &s1;
p->am = 2000;
```

### typedef
```c
typedef struct {
    double x, y;
} Point;
Point a = {1.0, 2.0};
```
Το typedef δίνει νέο όνομα σε τύπο: `typedef int Integer;`.

### Χαρακτηριστικά
- Οι δομές **μπορούν** να ανατεθούν ολόκληρες: `s2 = s1;` (αντιγράφει όλα τα πεδία, ακόμη και πίνακες-πεδία). Δεν μπορούν όμως να συγκριθούν με `==`.
- Πίνακες δομών: `struct student cls[50]; cls[3].grade`.
- Εμφωλευμένες δομές: `s.birth.year`.
- Σε συνάρτηση περνούν **με τιμή** (αντίγραφο). Για αλλαγή ή για αποδοτικότητα περνάμε δείκτη: `void upd(struct student *p)`.
- **Αυτοαναφορική δομή** (για λίστες): πεδίο-δείκτης στον ίδιο τύπο.
  ```c
  struct node { int data; struct node *next; };
  ```
@example
```c
typedef struct {
    char name[20];
    int pts;
} Team;

void win(Team *t) { t->pts += 3; }

int main(void) {
    Team league[3] = {{"ΑΕΚ", 10}, {"ΠΑΟ", 7}, {"ΟΣΦΠ", 12}};
    int i, best = 0;
    win(&league[1]);                       /* ΠΑΟ: 10 */
    for (i = 1; i < 3; i++)
        if (league[i].pts > league[best].pts) best = i;
    printf("%s %d", league[best].name, league[best].pts);   /* ΟΣΦΠ 12 */
    return 0;
}
```
@q mcq
pre: Τελεία για μεταβλητή δομής, βέλος για δείκτη σε δομή.
q: Αν `struct student *p = &s;` ποια έκφραση δίνει το πεδίο grade;
o: p.grade
o: p->grade
o: *p.grade
o: &p->grade
a: β
why: `p->grade` ≡ `(*p).grade`. Το `*p.grade` ερμηνεύεται ως `*(p.grade)` → σφάλμα.
@q tf
pre: Οι δομές αντιγράφονται ολόκληρες με ανάθεση.
q: Αν s1 και s2 είναι μεταβλητές του ίδιου τύπου δομής, η εντολή `s2 = s1;` αντιγράφει όλα τα πεδία.
a: Σ
why: Ναι, ακόμη και τα πεδία-πίνακες. (Αντίθετα, η σύγκριση `s1 == s2` **δεν** επιτρέπεται.)
@q fill
pre: Το typedef δίνει ψευδώνυμο σε τύπο.
q: Μετά από `typedef struct { int h, m; } Time;` δηλώνουμε μεταβλητή γράφοντας {{Time}} t; και προσπελαύνουμε τα λεπτά με {{t.m}}.
why: Χωρίς typedef θα χρειαζόταν η λέξη `struct`.
@q short
pre: Πίνακας δομών: πρώτα δείκτης πίνακα, μετά τελεία.
q: Με `struct P { int x, y; } v[3] = {{1,2},{3,4},{5,6}};` πόσο είναι το `v[2].x + v[0].y`;
a: 7
why: v[2].x = 5, v[0].y = 2 → **7**.
@q mcq
pre: Η δομή περνά σε συνάρτηση με τιμή, εκτός αν δοθεί δείκτης.
q: Η `void f(struct student s) { s.grade = 10; }` καλείται ως `f(x);`. Τι γίνεται με το x.grade;
o: Γίνεται 10
o: Μένει ίδιο
o: Συντακτικό σφάλμα
o: Γίνεται 0
a: β
why: Αλλάζει **αντίγραφο**. Για αλλαγή χρειάζεται `struct student *s` και `s->grade = 10`.
@q short
pre: Δείκτης σε δομή και τελεστής ->.
q: Τι τυπώνει;
```c
typedef struct { int a, b; } T;
T t = {2, 5};
T *p = &t;
p->a = p->a * p->b;
printf("%d", t.a + p->b);
```
a: 15
why: t.a = 2·5 = 10· 10 + 5 = **15**.
@q tf
pre: Η αυτοαναφορική δομή περιέχει δείκτη στον εαυτό της, όχι τον εαυτό της.
q: Η δήλωση `struct node { int d; struct node next; };` είναι έγκυρη.
a: Λ
why: Μια δομή δεν μπορεί να περιέχει **τον εαυτό της** (άπειρο μέγεθος). Περιέχει **δείκτη**: `struct node *next;`.
@q mcq
pre: Εμφωλευμένες δομές: αλυσίδα τελειών.
q: Με `struct date { int d, m, y; }; struct person { char n[20]; struct date born; } p;` πώς παίρνουμε το έτος γέννησης;
o: p.y
o: p.born.y
o: p->born->y
o: born.p.y
a: β
why: **p.born.y**.
@q fill
pre: Ο ορισμός δομής τελειώνει με ερωτηματικό.
q: Μετά το κλείσιμο του άγκιστρου στον ορισμό `struct X { int a; }` πρέπει να υπάρχει {{;}}.
why: Παράλειψή του προκαλεί συντακτικά σφάλματα στις επόμενες γραμμές.
@q short
pre: Ο βρόχος βρίσκει τον δείκτη του μεγίστου πεδίου.
q: Στο παράδειγμα με το Team, αν η `win` είχε κληθεί για την ΑΕΚ (θέση 0) αντί για τον ΠΑΟ, ποια ομάδα θα τυπωνόταν; (γράψε το όνομα)
a: ΑΕΚ
why: ΑΕΚ: 10 + 3 = 13 > 12 της ΟΣΦΠ → **ΑΕΚ 13**.

@lesson c-mem | Δυναμική διαχείριση μνήμης
@theory
### Γιατί
Οι στατικοί πίνακες έχουν **σταθερό** μέγεθος. Με **δυναμική μνήμη** ζητάμε μνήμη **κατά την εκτέλεση**, όση χρειάζεται (π.χ. n που δίνει ο χρήστης).

### stdlib.h
| Συνάρτηση | Τι κάνει |
|---|---|
| `malloc(bytes)` | δεσμεύει bytes και επιστρέφει δείκτη (`void *`). Τα περιεχόμενα είναι **σκουπίδια**. |
| `calloc(n, size)` | δεσμεύει n·size bytes **μηδενισμένα** |
| `realloc(p, νέο_μέγεθος)` | αλλάζει μέγεθος (μπορεί να μετακινήσει τα δεδομένα) |
| `free(p)` | **αποδεσμεύει** |

```c
int n, *a;
scanf("%d", &n);
a = (int *) malloc(n * sizeof(int));
if (a == NULL) { printf("Ανεπαρκής μνήμη\n"); exit(1); }
for (i = 0; i < n; i++) a[i] = 0;      /* χρησιμοποιείται σαν πίνακας */
...
free(a);
a = NULL;
```

### Σωρός vs στοίβα
- Οι **τοπικές** μεταβλητές ζουν στη **στοίβα** και καταστρέφονται αυτόματα.
- Η μνήμη του malloc ζει στον **σωρό (heap)** μέχρι να καλέσεις **free**. Επιβιώνει και μετά την επιστροφή της συνάρτησης που την δέσμευσε.

### Συνηθισμένα λάθη
| Λάθος | Τι σημαίνει |
|---|---|
| **Διαρροή μνήμης (memory leak)** | ξεχνάς το free ή χάνεις τον δείκτη πριν το free |
| **Κρεμάμενος δείκτης (dangling)** | χρήση μνήμης μετά το free |
| **Διπλό free** | free δύο φορές στην ίδια μνήμη |
| Ξεχασμένο `sizeof` | `malloc(n)` αντί για `malloc(n * sizeof(int))` |
| Χωρίς έλεγχο NULL | το malloc μπορεί να αποτύχει |
@example
**Συνάρτηση που φτιάχνει και επιστρέφει δυναμικό πίνακα:**
```c
int *create(int n) {
    int i, *p = malloc(n * sizeof(int));
    if (p == NULL) return NULL;
    for (i = 0; i < n; i++) p[i] = i * i;
    return p;               /* ✔ η μνήμη ΔΕΝ χάνεται στην επιστροφή */
}
int main(void) {
    int *v = create(5);     /* {0,1,4,9,16} */
    printf("%d", v[3]);     /* 9 */
    free(v);
    return 0;
}
```
**Διαρροή:**
```c
p = malloc(100);
p = malloc(200);   /* ✗ τα πρώτα 100 bytes δεν μπορούν πια να αποδεσμευτούν */
```
@q mcq
pre: Η malloc ζητά bytes· για n ακεραίους χρειάζεσαι n · sizeof(int).
q: Ποια εντολή δεσμεύει σωστά χώρο για **n ακεραίους**;
o: p = malloc(n);
o: p = malloc(n * sizeof(int));
o: p = malloc(sizeof(n));
o: p = malloc(int[n]);
a: β
why: Το malloc δέχεται **bytes**: n · sizeof(int).
@q tf
pre: Η μνήμη του σωρού ζει μέχρι το free.
q: Η μνήμη που δεσμεύεται με malloc μέσα σε μια συνάρτηση αποδεσμεύεται αυτόματα όταν η συνάρτηση επιστρέψει.
a: Λ
why: Ζει στον **σωρό** μέχρι να κληθεί **free** (ή να τερματίσει το πρόγραμμα). Γι' αυτό μπορεί να επιστραφεί με ασφάλεια.
@q fill
pre: Δύο συναρτήσεις δέσμευσης: η μία μηδενίζει.
q: Η {{calloc}} δεσμεύει μνήμη και τη μηδενίζει, ενώ η {{malloc}} αφήνει απροσδιόριστα περιεχόμενα.
why: `calloc(n, size)` έναντι `malloc(bytes)`.
@q mcq
pre: Διαρροή = δεσμευμένη μνήμη χωρίς δείκτη για να αποδεσμευτεί.
q: Τι είναι **διαρροή μνήμης**;
o: Η χρήση μνήμης μετά το free
o: Δεσμευμένη μνήμη που δεν αποδεσμεύεται ποτέ, συχνά επειδή χάθηκε ο δείκτης της
o: Η υπερχείλιση της στοίβας
o: Το διπλό free
a: β
why: Ο χώρος μένει δεσμευμένος μέχρι το τέλος του προγράμματος. Σε προγράμματα που τρέχουν πολύ, η μνήμη «τελειώνει».
@q tf
pre: Το malloc μπορεί να αποτύχει.
q: Πρέπει πάντα να ελέγχουμε αν η malloc επέστρεψε NULL.
a: Σ
why: Αν δεν υπάρχει διαθέσιμη μνήμη επιστρέφει **NULL**. Η χρήση του χωρίς έλεγχο προκαλεί κατάρρευση.
@q short
pre: Η δυναμική μνήμη χρησιμοποιείται με σύνταξη πίνακα.
q: Τι τυπώνει;
```c
int i, *p = malloc(4 * sizeof(int));
for (i = 0; i < 4; i++) p[i] = 10 - i;
printf("%d", p[1] + *(p + 3));
free(p);
```
a: 16
why: p[1] = 9, p[3] = 7 → **16**.
@q mcq
pre: Μετά το free ο δείκτης εξακολουθεί να κρατά την παλιά διεύθυνση.
q: Γιατί συνιστάται `p = NULL;` αμέσως μετά το `free(p);`;
o: Για να ξαναδεσμευτεί αυτόματα
o: Για να μη χρησιμοποιηθεί κατά λάθος η αποδεσμευμένη μνήμη (κρεμάμενος δείκτης)
o: Γιατί αλλιώς το free δεν ολοκληρώνεται
o: Δεν έχει νόημα
a: β
why: Μια μελλοντική χρήση θα αποτύχει «καθαρά» (NULL) αντί να αλλοιώσει δεδομένα στα κρυφά.
@q short
pre: Πόσα bytes ζητάει η κλήση;
q: Αν sizeof(double) = 8, πόσα bytes δεσμεύει η `calloc(25, sizeof(double))`;
a: 200
why: 25 · 8 = **200**.
@q fill
pre: Τοπικές στη στοίβα, malloc στον σωρό.
q: Οι τοπικές μεταβλητές αποθηκεύονται στη {{στοίβα | stack}}, ενώ η μνήμη της malloc στον {{σωρό | heap}}.
why: Η στοίβα διαχειρίζεται αυτόματα, ο σωρός χειροκίνητα.
@q tf
pre: Η realloc μπορεί να μετακινήσει το μπλοκ.
q: Μετά από `q = realloc(p, νέο);` πρέπει να χρησιμοποιούμε το q, γιατί τα δεδομένα μπορεί να έχουν μετακινηθεί σε άλλη διεύθυνση.
a: Σ
why: Η realloc επιστρέφει πιθανώς **νέα** διεύθυνση (και NULL σε αποτυχία, οπότε το p παραμένει έγκυρο).

@lesson c-list | Συνδεδεμένες λίστες στη C
@theory
### Κόμβος
```c
typedef struct node {
    int data;
    struct node *next;
} Node;
```

### Δημιουργία κόμβου
```c
Node *newNode(int x) {
    Node *n = malloc(sizeof(Node));
    if (n == NULL) exit(1);
    n->data = x;
    n->next = NULL;
    return n;
}
```

### Εισαγωγή στην αρχή
Η κεφαλή αλλάζει, άρα είτε την επιστρέφουμε είτε περνάμε `Node **`:
```c
Node *push_front(Node *head, int x) {
    Node *n = newNode(x);
    n->next = head;
    return n;                 /* νέα κεφαλή */
}
head = push_front(head, 5);
```

### Διάσχιση
```c
for (Node *p = head; p != NULL; p = p->next)
    printf("%d ", p->data);
```

### Εισαγωγή στο τέλος
Διάσχιση μέχρι τον κόμβο με `p->next == NULL` και μετά `p->next = newNode(x)`. Ειδική περίπτωση: **άδεια λίστα**.

### Διαγραφή κόμβου με τιμή x
```c
Node *del(Node *head, int x) {
    Node *p = head, *prev = NULL;
    while (p != NULL && p->data != x) { prev = p; p = p->next; }
    if (p == NULL) return head;                  /* δεν βρέθηκε */
    if (prev == NULL) head = p->next;            /* ήταν ο πρώτος */
    else prev->next = p->next;
    free(p);
    return head;
}
```

### Αποδέσμευση όλης της λίστας
```c
while (head) {
    Node *t = head;
    head = head->next;
    free(t);
}
```
**Πρώτα** κρατάς τον επόμενο, **μετά** κάνεις free.
@example
```c
Node *head = NULL;
head = push_front(head, 3);   /* 3 */
head = push_front(head, 8);   /* 8 → 3 */
head = push_front(head, 1);   /* 1 → 8 → 3 */
head = del(head, 8);          /* 1 → 3 */
for (Node *p = head; p; p = p->next) printf("%d ", p->data);
```
**Έξοδος:** `1 3`

Η εισαγωγή στην αρχή **αντιστρέφει** τη σειρά: όποιος μπήκε τελευταίος είναι πρώτος.
@q mcq
pre: Ο τελεστής -> προσπελαύνει πεδίο μέσω δείκτη.
q: Πώς προχωράμε τον δείκτη p στον επόμενο κόμβο;
o: p++;
o: p = p->next;
o: p = next;
o: p->next = p;
a: β
why: Οι κόμβοι **δεν** είναι συνεχόμενοι στη μνήμη, άρα το p++ δεν έχει νόημα. Ακολουθείς τον δείκτη `next`.
@q short
pre: Η εισαγωγή στην αρχή βάζει κάθε νέο στοιχείο μπροστά.
q: Ξεκινώντας από άδεια λίστα, κάνουμε push_front(2), push_front(4), push_front(6). Τι τυπώνει η διάσχιση; (με κενά)
a: 6 4 2
why: Κάθε νέο μπαίνει μπροστά → **6 4 2**.
@q tf
pre: Στην αποδέσμευση λίστας πρέπει να κρατήσεις τον επόμενο πριν το free.
q: Ο βρόχος `for (p = head; p != NULL; p = p->next) free(p);` αποδεσμεύει σωστά τη λίστα.
a: Λ
why: Μετά το `free(p)` το `p->next` διαβάζεται από **αποδεσμευμένη** μνήμη. Κράτα πρώτα `t = p->next`.
@q fill
pre: Ο νέος κόμβος στην αρχή πρέπει να δείχνει στην παλιά κεφαλή.
q: Στην push_front, μετά τη δημιουργία του n εκτελούμε {{n->next}} = head; και επιστρέφουμε το {{n}} ως νέα κεφαλή.
why: Έτσι ο νέος κόμβος γίνεται πρώτος και δείχνει στην υπόλοιπη λίστα.
@q mcq
pre: Η διαγραφή του πρώτου κόμβου αλλάζει την κεφαλή.
q: Στη `del`, γιατί ελέγχουμε `if (prev == NULL)`;
o: Για να δούμε αν η λίστα είναι άδεια
o: Γιατί αν ο κόμβος που διαγράφεται είναι ο πρώτος, πρέπει να αλλάξει η κεφαλή
o: Για να αποφύγουμε το free
o: Δεν χρειάζεται
a: β
why: Δεν υπάρχει προηγούμενος κόμβος για να «παρακάμψει» τον p. Η **κεφαλή** μετακινείται.
@q short
pre: Ιχνηλάτησε τη λίστα.
q: Λίστα 5 → 9 → 2 → 7 → NULL. Τι επιστρέφει η συνάρτηση;
```c
int f(Node *h) { int m = h->data; for (h = h->next; h; h = h->next) if (h->data > m) m = h->data; return m; }
```
a: 9
why: Βρίσκει το **μέγιστο**: 9.
@q tf
pre: Η κενή λίστα είναι ειδική περίπτωση.
q: Μια άδεια λίστα αναπαρίσταται με head == NULL.
a: Σ
why: Δεν υπάρχει κανένας κόμβος. Οι συναρτήσεις πρέπει να χειρίζονται αυτή την περίπτωση (π.χ. εισαγωγή στο τέλος).
@q mcq
pre: Για να αλλάξει μια void συνάρτηση την κεφαλή του καλούντος χρειάζεται δείκτη σε δείκτη.
q: Ποια υπογραφή επιτρέπει σε μια **void** συνάρτηση να αλλάξει την κεφαλή `Node *head` του καλούντος;
o: void ins(Node head, int x)
o: void ins(Node *head, int x)
o: void ins(Node **head, int x)
o: void ins(int x)
a: γ
why: Με `Node **head` και κλήση `ins(&head, x)` γράφεις `*head = νέος κόμβος`.
@q short
pre: Μέτρησε τους κόμβους κατά τη διάσχιση.
q: Λίστα 4 → 4 → 1 → 4 → NULL. Μετά από `head = del(head, 4);` (διαγράφει **μόνο την πρώτη** εμφάνιση), πόσοι κόμβοι μένουν;
a: 3
why: Διαγράφεται μόνο ο πρώτος 4 → 4 → 1 → 4 → **3** κόμβοι.
@q fill
pre: Ο νέος κόμβος πρέπει να δείχνει «πουθενά» μέχρι να συνδεθεί.
q: Στη newNode, το πεδίο next αρχικοποιείται σε {{NULL}} και η μνήμη δεσμεύεται με malloc({{sizeof(Node)}}).
why: Χωρίς αρχικοποίηση, το next θα είχε τυχαία τιμή.

@lesson c-file | Αρχεία στη C
@theory
### Άνοιγμα και κλείσιμο
```c
FILE *fp = fopen("data.txt", "r");
if (fp == NULL) { printf("Δεν άνοιξε\n"); return 1; }
...
fclose(fp);
```

| Τρόπος | Σημασία |
|---|---|
| `"r"` | ανάγνωση (το αρχείο πρέπει να υπάρχει) |
| `"w"` | εγγραφή (δημιουργεί ή **σβήνει** το παλιό περιεχόμενο) |
| `"a"` | προσθήκη στο τέλος |
| `"r+"`, `"w+"`, `"a+"` | ανάγνωση και εγγραφή |
| `"rb"`, `"wb"` | δυαδικά αρχεία |

### Κειμένου
- `fprintf(fp, "%d %s\n", x, s);` / `fscanf(fp, "%d", &x);`
- `fgets(buf, N, fp);` / `fputs(s, fp);`
- `fgetc(fp)` / `fputc(c, fp)`
- **Τέλος αρχείου:** η fscanf επιστρέφει **EOF** (ή λιγότερες τιμές από όσες ζητήθηκαν), η fgets επιστρέφει **NULL**, η fgetc επιστρέφει **EOF**.

Τυπικός βρόχος:
```c
while (fscanf(fp, "%d", &x) == 1) sum += x;
```

### Δυαδικά
- `fwrite(&rec, sizeof(rec), 1, fp);` / `fread(&rec, sizeof(rec), 1, fp);`
- Επιστρέφουν πόσα στοιχεία μεταφέρθηκαν.
- `fseek(fp, offset, SEEK_SET)` για τυχαία προσπέλαση, `ftell`, `rewind`.

### Προκαθορισμένα ρεύματα
`stdin` (πληκτρολόγιο), `stdout` (οθόνη), `stderr` (σφάλματα). Το `printf(...)` ≡ `fprintf(stdout, ...)`.
@example
**Εγγραφή και ανάγνωση βαθμών:**
```c
FILE *f = fopen("grades.txt", "w");
fprintf(f, "%d\n%d\n%d\n", 7, 9, 4);
fclose(f);

int x, s = 0, n = 0;
f = fopen("grades.txt", "r");
if (f == NULL) return 1;
while (fscanf(f, "%d", &x) == 1) { s += x; n++; }
fclose(f);
printf("Μ.Ο. = %.2f\n", (double)s / n);    /* 6.67 */
```
**Παγίδα:** το `while (!feof(f))` συχνά επεξεργάζεται την **τελευταία** τιμή δύο φορές. Ο έλεγχος με την επιστρεφόμενη τιμή της fscanf είναι ασφαλέστερος.
@q mcq
pre: Ο τρόπος "w" δημιουργεί νέο αρχείο ή μηδενίζει το υπάρχον.
q: Τι συμβαίνει αν ανοίξουμε με `"w"` ένα αρχείο που ήδη υπάρχει;
o: Προστίθενται δεδομένα στο τέλος
o: Το παλιό περιεχόμενο σβήνεται
o: Αποτυγχάνει
o: Ανοίγει μόνο για ανάγνωση
a: β
why: Το "w" **περικόπτει** το αρχείο. Για προσθήκη στο τέλος χρησιμοποιείς "a".
@q tf
pre: Η fopen επιστρέφει NULL αν αποτύχει.
q: Πρέπει να ελέγχουμε αν η fopen επέστρεψε NULL πριν χρησιμοποιήσουμε τον δείκτη FILE.
a: Σ
why: π.χ. αν το αρχείο δεν υπάρχει (σε "r") ή δεν έχουμε δικαιώματα. Η χρήση NULL → κατάρρευση.
@q fill
pre: Οι εκδόσεις των printf/scanf για αρχεία έχουν ένα f μπροστά και παίρνουν πρώτο όρισμα το FILE*.
q: Για εγγραφή σε αρχείο με μορφοποίηση χρησιμοποιούμε την {{fprintf}} και για ανάγνωση την {{fscanf}}.
why: Π.χ. `fprintf(fp, "%d", x);`
@q short
pre: Η fscanf επιστρέφει το πλήθος των τιμών που διάβασε επιτυχώς.
q: Το αρχείο περιέχει «5 8 x 3». Πόσες φορές εκτελείται το σώμα του `while (fscanf(f, "%d", &v) == 1) {…}`;
a: 2
why: Διαβάζει 5 και 8. Στο «x» η fscanf επιστρέφει 0 → ο βρόχος σταματά → **2**.
@q mcq
pre: Τα τρία προκαθορισμένα ρεύματα.
q: Ποια κλήση είναι ισοδύναμη με `printf("Hi");`
o: fprintf(stdin, "Hi");
o: fprintf(stdout, "Hi");
o: fputs(stderr, "Hi");
o: fscanf(stdout, "Hi");
a: β
why: Η printf γράφει στο **stdout**.
@q tf
pre: Η fclose αδειάζει τα buffers και ελευθερώνει τον πόρο.
q: Αν ξεχάσουμε το fclose μετά από εγγραφές, υπάρχει κίνδυνος κάποια δεδομένα να μη γραφτούν στο αρχείο.
a: Σ
why: Τα δεδομένα μπορεί να βρίσκονται ακόμη σε **buffer**. Το fclose (ή το fflush) τα γράφει στον δίσκο.
@q fill
pre: Δυαδική εγγραφή ολόκληρης δομής.
q: Για εγγραφή μιας δομής rec σε δυαδικό αρχείο: `{{fwrite}}(&rec, sizeof(rec), 1, fp);` και για ανάγνωση: `{{fread}}(&rec, sizeof(rec), 1, fp);`
why: Επιστρέφουν το πλήθος των στοιχείων που μεταφέρθηκαν.
@q mcq
pre: Η fgets επιστρέφει NULL στο τέλος του αρχείου.
q: Ποια συνθήκη βρόχου διαβάζει σωστά ένα αρχείο κειμένου γραμμή-γραμμή;
o: while (fgets(buf, 100, fp) != NULL)
o: while (fgets(buf, 100, fp) == EOF)
o: while (fp != NULL)
o: while (buf != NULL)
a: α
why: Η fgets επιστρέφει **NULL** στο τέλος του αρχείου ή σε σφάλμα.
@q short
pre: Ο τρόπος "a" γράφει πάντα στο τέλος.
q: Ένα αρχείο έχει 3 γραμμές. Το ανοίγουμε με "a" και γράφουμε 2 γραμμές. Πόσες γραμμές έχει μετά;
a: 5
why: Το "a" **προσθέτει** στο τέλος → 3 + 2 = **5**.
@q tf
pre: Το feof γίνεται αληθές μόνο αφού μια ανάγνωση προσπαθήσει να περάσει το τέλος.
q: Ο βρόχος `while (!feof(f)) { fscanf(f, "%d", &x); s += x; }` αθροίζει πάντα σωστά τους ακεραίους ενός αρχείου.
a: Λ
why: Το feof γίνεται αληθές **μετά** από αποτυχημένη ανάγνωση, οπότε η τελευταία τιμή μπορεί να προστεθεί δύο φορές. Έλεγχε την επιστροφή της fscanf.
