@lesson c-intro | Δομή προγράμματος C και μεταγλώττιση
@theory
### Το πρώτο πρόγραμμα
```c
#include <stdio.h>      /* οδηγία προεπεξεργαστή: δηλώσεις της printf */

int main(void)          /* η εκτέλεση ξεκινά ΠΑΝΤΑ από τη main */
{
    printf("Γεια σου, κόσμε!\n");
    return 0;           /* 0 = επιτυχής τερματισμός */
}
```
- Ένα πρόγραμμα C είναι **σύνολο συναρτήσεων**. Υποχρεωτική είναι μόνο η **main**.
- Κάθε εντολή τελειώνει με **`;`**. Τα **άγκιστρα `{ }`** ορίζουν μπλοκ.
- Σχόλια: `/* ... */` (πολλαπλών γραμμών) και `// ...` (C99).
- Η C **ξεχωρίζει πεζά/κεφαλαία**: `Main` ≠ `main`.

### Από τον πηγαίο κώδικα στο εκτελέσιμο
1. **Προεπεξεργαστής:** εκτελεί τις `#include`, `#define` (απλή αντικατάσταση κειμένου).
2. **Μεταγλωττιστής:** C → αντικειμενικός κώδικας (.o/.obj). Εδώ βγαίνουν τα **συντακτικά** σφάλματα.
3. **Συνδέτης (linker):** ενώνει με βιβλιοθήκες (π.χ. την printf) → εκτελέσιμο. Εδώ βγαίνουν σφάλματα όπως «undefined reference».
4. **Φόρτωση και εκτέλεση.** Εδώ φαίνονται τα σφάλματα **εκτέλεσης** και τα **λογικά**.

Στο ΕΑΠ χρησιμοποιείται συνήθως το **Dev-C++** (μεταγλωττιστής gcc).

### Χαρακτήρες διαφυγής
| Ακολουθία | Σημασία |
|---|---|
| `\n` | νέα γραμμή |
| `\t` | στηλοθέτης |
| `\\` | ανάποδη κάθετος |
| `\"` | εισαγωγικά |
| `\0` | μηδενικός χαρακτήρας (τέλος συμβολοσειράς) |

### Σταθερές με #define
```c
#define PI 3.14159
#define N 100
```
Δεν είναι μεταβλητές. Ο προεπεξεργαστής αντικαθιστά το κείμενο **πριν** από τη μεταγλώττιση. Δεν μπαίνει `;` στο τέλος.
@example
```c
#include <stdio.h>
#define N 3

int main(void) {
    int i;
    for (i = 1; i <= N; i++)
        printf("Γραμμή %d\n", i);
    return 0;
}
```
**Έξοδος:**
```
Γραμμή 1
Γραμμή 2
Γραμμή 3
```
**Συνηθισμένο λάθος:** `#define N 3;` → το `i <= N` γίνεται `i <= 3;` και προκαλεί συντακτικό σφάλμα σε άσχετο σημείο.

@lesson c-types | Μεταβλητές, τύποι, printf και scanf
@theory
### Βασικοί τύποι
| Τύπος | Τυπικό μέγεθος | Τι κρατά | printf/scanf |
|---|---|---|---|
| `char` | 1 byte | χαρακτήρα (μικρό ακέραιο) | `%c` |
| `int` | 4 bytes | ακέραιο | `%d` |
| `float` | 4 bytes | πραγματικό απλής ακρίβειας | `%f` |
| `double` | 8 bytes | πραγματικό διπλής ακρίβειας | printf `%f`, **scanf `%lf`** |
| `long` | 4 ή 8 bytes | μεγαλύτερο ακέραιο | `%ld` |

Τροποποιητές: `short`, `long`, `unsigned` (μόνο μη αρνητικοί, διπλάσιο θετικό εύρος).

Το `sizeof(τύπος)` δίνει το μέγεθος σε bytes.

### Μεταβλητές
- Δηλώνονται **πριν** από τη χρήση: `int x, y = 5; double z = 2.5;`
- **Μη αρχικοποιημένη** τοπική μεταβλητή έχει **απρόβλεπτη (σκουπίδι)** τιμή.
- Ονόματα: γράμματα, ψηφία, `_`. Δεν ξεκινούν με ψηφίο. Δεν επιτρέπονται οι δεσμευμένες λέξεις (`int`, `for` …).
- `const int N = 10;` → μεταβλητή που δεν αλλάζει.

### printf
```c
printf("x = %d, y = %.2f\n", x, y);
```
- `%5d`: πλάτος 5 (δεξιά στοίχιση).
- `%.2f`: 2 δεκαδικά.
- `%-5d`: αριστερή στοίχιση.
- `%%`: τυπώνει το σύμβολο %.

### scanf
```c
scanf("%d", &x);        /* ΠΡΟΣΟΧΗ στο & : δίνουμε τη ΔΙΕΥΘΥΝΣΗ της x */
scanf("%lf", &z);       /* double → %lf */
scanf("%d %d", &a, &b);
```
- Χωρίς `&` → σφάλμα εκτέλεσης (γράφει σε τυχαία θέση).
- Για πίνακα χαρακτήρων **δεν** βάζουμε `&`: `scanf("%s", name);`
- Η scanf επιστρέφει πόσες τιμές διάβασε επιτυχώς — χρήσιμο για έλεγχο.

### Χαρακτήρες
Ένας `char` είναι στην ουσία ακέραιος (κωδικός ASCII):
- `'A' + 1 == 'B'`
- `printf("%d", 'A')` → 65
@example
```c
#include <stdio.h>
int main(void) {
    int a;  double b;
    printf("Δώσε ακέραιο και πραγματικό: ");
    scanf("%d %lf", &a, &b);
    printf("[%5d] [%-5d] [%.1f] [%c]\n", a, a, b, 'A' + 2);
    return 0;
}
```
Με είσοδο `42 3.14159` η έξοδος είναι:
```
[   42] [42   ] [3.1] [C]
```

@lesson c-ops | Τελεστές και εκφράσεις
@theory
### Αριθμητικοί
`+ - * / %`
- **Ακέραια διαίρεση:** `7 / 2` = **3** (κόβεται το δεκαδικό). Αν έστω ένας τελεσταίος είναι πραγματικός: `7 / 2.0` = **3.5**.
- `%` = υπόλοιπο, **μόνο για ακεραίους**. `7 % 3` = 1, `-7 % 3` = −1 (C99).

### Μετατροπές τύπων
- **Αυτόματη προαγωγή:** int με double → double.
- **Ρητή (cast):** `(double)a / b` → πραγματική διαίρεση.
- Ανάθεση double σε int → **αποκοπή**: `int x = 3.9;` → 3.

### Σχεσιακοί και λογικοί
- Σχεσιακοί: `== != < > <= >=`. Το αποτέλεσμα είναι **1** (αληθές) ή **0** (ψευδές).
- Λογικοί: `&&` (ΚΑΙ), `||` (Ή), `!` (ΟΧΙ).
- Στη C **οποιαδήποτε μη μηδενική τιμή είναι αληθής**.
- **Βραχυκύκλωμα:** στο `a && b`, αν a == 0 το b **δεν** υπολογίζεται. Στο `a || b`, αν a ≠ 0 το b δεν υπολογίζεται.
- **Κλασικό λάθος:** `if (x = 5)` (ανάθεση, πάντα αληθής) αντί για `if (x == 5)`.

### Αύξηση/μείωση και σύνθετη ανάθεση
- `x++` (μεταθεματικός): η έκφραση έχει την **παλιά** τιμή.
- `++x` (προθεματικός): η έκφραση έχει τη **νέα** τιμή.
- `x += 3` ≡ `x = x + 3`. Ομοίως `-= *= /= %=`.

### Τριαδικός τελεστής
`συνθήκη ? α : β` → α αν η συνθήκη είναι αληθής, αλλιώς β. Π.χ. `max = (a > b) ? a : b;`

### Προτεραιότητα (από υψηλή προς χαμηλή — τα βασικά)
1. `()` `[]` `->` `.`
2. μοναδιαίοι: `! ++ -- -` (αρνητικό), `(τύπος)`, `*` (περιεχόμενο), `&` (διεύθυνση), `sizeof`
3. `* / %`
4. `+ -`
5. `< <= > >=`
6. `== !=`
7. `&&`
8. `||`
9. `?:`
10. `= += -= …` (ανάθεση, **από δεξιά προς αριστερά**)

Οι περισσότεροι δυαδικοί τελεστές της ίδιας προτεραιότητας εκτελούνται **από αριστερά προς τα δεξιά**.
@example
```c
int a = 7, b = 2, c;
double d;
d = a / b;            /* 3.0  ← ακέραια διαίρεση ΠΡΙΝ την ανάθεση */
d = (double)a / b;    /* 3.5 */
c = a % b;            /* 1 */
c = a > b && b > 5;   /* 1 && 0 → 0 */
c = !(a == 7);        /* 0 */
c = a++ + ++b;        /* 7 + 3 = 10, μετά a=8, b=3 */
c = (a > 5) ? 100 : 200;   /* 100 */
```
**Βραχυκύκλωμα που σώζει:** `if (n != 0 && sum / n > 10)` — αν n == 0, η διαίρεση **δεν** εκτελείται ποτέ.
@q short

@q fill

a: -1
why: −13 / 4 = −3 (αποκοπή προς το 0), −13 − (−3·4) = **−1**.

@lesson c-if | Επιλογή: if, else, switch
@theory
### if / else
```c
if (συνθήκη)
    εντολή;
else
    εντολή;
```
- Για περισσότερες εντολές σε κλάδο → **άγκιστρα { }**.
- **Κρεμάμενο else:** το `else` ανήκει στο **πλησιέστερο** `if` που δεν έχει else.
  - Η στοίχιση **δεν** μετράει για τον μεταγλωττιστή.
- **Κλιμακωτό else if:** εκτελείται μόνο ο πρώτος αληθής κλάδος.
  ```c
  if (b >= 9) printf("Άριστα");
  else if (b >= 7) printf("Πολύ καλά");
  else if (b >= 5) printf("Καλά");
  else printf("Απορρίπτεται");
  ```
- **Παγίδα:** `if (x > 0);` → το `;` είναι κενή εντολή, και ό,τι ακολουθεί εκτελείται **πάντα**.

### switch
```c
switch (ακέραια_έκφραση) {
    case 1:  ...; break;
    case 2:
    case 3:  ...; break;      /* ίδια ενέργεια για 2 και 3 */
    default: ...;
}
```
- Η έκφραση πρέπει να είναι **ακέραια** ή **χαρακτήρας** (όχι double ή συμβολοσειρά).
- Οι ετικέτες case είναι **σταθερές**.
- **Χωρίς break** η εκτέλεση «πέφτει» (fall-through) στις επόμενες case.
- Το `default` εκτελείται αν καμία case δεν ταιριάζει (προαιρετικό).
@example
**Fall-through:**
```c
int k = 2;
switch (k) {
    case 1: printf("Α");
    case 2: printf("Β");
    case 3: printf("Γ"); break;
    case 4: printf("Δ");
}
```
Τυπώνει **ΒΓ**: μπαίνει στο case 2 και, χωρίς break, συνεχίζει στο case 3 μέχρι το break.

**Κρεμάμενο else:**
```c
if (a > 0)
    if (b > 0) printf("1");
else printf("2");        /* ανήκει στο if (b > 0) παρά τη στοίχιση! */
```
Με a = −1 **δεν τυπώνει τίποτα**.

@lesson c-loops | Βρόχοι: while, for, do-while, break, continue
@theory
### while
```c
while (συνθήκη) {
    ...
}
```
Ο έλεγχος γίνεται **πριν** από το σώμα, άρα μπορεί να εκτελεστεί **0** φορές.

### for
```c
for (αρχικοποίηση; συνθήκη; βήμα) {
    ...
}
```
Ισοδυναμεί με:
```c
αρχικοποίηση;
while (συνθήκη) {
    ...
    βήμα;
}
```
- Οποιοδήποτε από τα τρία μέρη μπορεί να λείπει: `for (;;)` = ατέρμονος βρόχος.
- Μετά το τέλος του `for (i = 0; i < n; i++)` ισχύει **i == n**.

### do-while
```c
do {
    ...
} while (συνθήκη);      /* προσοχή στο ; */
```
Το σώμα εκτελείται **τουλάχιστον μία φορά**. Ιδανικό για έλεγχο εισόδου:
```c
do {
    printf("Δώσε 1-10: ");
    scanf("%d", &x);
} while (x < 1 || x > 10);
```

### break και continue
- **break:** έξοδος από τον **πιο εσωτερικό** βρόχο (ή switch).
- **continue:** πηγαίνει αμέσως στην **επόμενη επανάληψη**. Στο for εκτελείται πρώτα το βήμα.

### Συνηθισμένα λάθη
- `;` μετά το for/while: `for (i = 0; i < n; i++);` → κενό σώμα.
- Λάθος όριο (off-by-one): `<=` αντί για `<` σε πίνακα n στοιχείων.
- Ξεχασμένη ενημέρωση της μεταβλητής ελέγχου στο while → ατέρμονος βρόχος.
@example
```c
int i, s = 0;
for (i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;   /* παρακάμπτει τους άρτιους */
    if (i > 7) break;           /* σταματά στο 9 */
    s += i;
}
printf("%d %d", s, i);
```
- i = 1, 3, 5, 7 προστίθενται → s = **16**.
- Στο i = 9 εκτελείται το break, με i = **9**.

Τυπώνει **16 9**.

**Εμφωλευμένοι βρόχοι — τρίγωνο:**
```c
for (i = 1; i <= 3; i++) {
    for (j = 1; j <= i; j++) printf("*");
    printf("\n");
}
```
```

***
```

@lesson c-func | Συναρτήσεις, πρωτότυπα, εμβέλεια
@theory
### Ορισμός και κλήση
```c
int max(int a, int b);          /* πρωτότυπο (δήλωση) */

int main(void) {
    int m = max(3, 8);          /* κλήση με ορίσματα */
    printf("%d", m);
    return 0;
}

int max(int a, int b) {         /* ορισμός */
    return (a > b) ? a : b;
}
```
- Το **πρωτότυπο** ενημερώνει τον μεταγλωττιστή για τον τύπο επιστροφής και τις παραμέτρους. Χρειάζεται αν η συνάρτηση ορίζεται **μετά** τη χρήση της.
- Η `return` τερματίζει τη συνάρτηση και επιστρέφει τιμή.
- Η `void` συνάρτηση δεν επιστρέφει τιμή: `void print_line(int n)`.
- Μια συνάρτηση επιστρέφει **μία** τιμή. Για περισσότερες χρησιμοποιούμε δείκτες (πέρασμα με αναφορά).

### Μεταβίβαση παραμέτρων
Στη C όλα περνούν **με τιμή (αντίγραφο)**. Η συνάρτηση **δεν** μπορεί να αλλάξει τις μεταβλητές του καλούντος, **εκτός** αν της δώσουμε τη **διεύθυνσή** τους (δείκτη).

Οι **πίνακες** περνούν ως διεύθυνση του πρώτου στοιχείου, άρα η συνάρτηση **μπορεί** να αλλάξει τα στοιχεία τους.

### Εμβέλεια και διάρκεια ζωής
| Είδος | Ορατότητα | Διάρκεια | Αρχική τιμή |
|---|---|---|---|
| **Τοπική** (auto) | μόνο στο μπλοκ της | όσο τρέχει το μπλοκ | σκουπίδια |
| **Καθολική** | από τη δήλωση και κάτω, σε όλο το αρχείο | όλο το πρόγραμμα | 0 |
| **static τοπική** | μόνο στη συνάρτηση | **όλο το πρόγραμμα**: κρατά την τιμή μεταξύ κλήσεων | 0, αρχικοποίηση **μία** φορά |

Τοπική μεταβλητή με το ίδιο όνομα με καθολική **την κρύβει**.

### Βιβλιοθήκες
- `math.h`: sqrt, pow, fabs, sin…
- `stdlib.h`: rand, srand, abs, malloc, exit.
- `string.h`: strlen, strcpy, strcmp, strcat.
- `ctype.h`: isdigit, isalpha, toupper, tolower.
@example
```c
#include <stdio.h>
int g = 10;                 /* καθολική */

int counter(void) {
    static int c = 0;       /* αρχικοποιείται ΜΙΑ φορά */
    c++;
    return c;
}

void f(int g) {             /* παράμετρος g κρύβει την καθολική */
    g = g * 2;
    printf("μέσα: %d\n", g);
}

int main(void) {
    counter(); counter();
    printf("%d\n", counter());   /* 3 */
    f(5);                        /* μέσα: 10 */
    printf("%d\n", g);           /* 10 — η καθολική δεν άλλαξε */
    return 0;
}
```

@lesson c-rec | Αναδρομή στη C
@theory
### Αναδρομικές συναρτήσεις
```c
long fact(int n) {
    if (n <= 1) return 1;          /* βάση */
    return n * fact(n - 1);        /* αναδρομικό βήμα */
}
```
Σε κάθε κλήση δημιουργείται νέο **πλαίσιο στη στοίβα** με δικά του n και δική του διεύθυνση επιστροφής.

### Χρήσιμα πρότυπα
| Πρόβλημα | Αναδρομική ιδέα |
|---|---|
| Άθροισμα 1..n | s(n) = n + s(n−1), s(0) = 0 |
| Δύναμη | power(x, n) = x · power(x, n−1) |
| Πλήθος ψηφίων | d(n) = 1 αν n < 10, αλλιώς 1 + d(n/10) |
| Άθροισμα πίνακα | sum(a, n) = a[n−1] + sum(a, n−1), sum(a,0) = 0 |
| Δυαδική αναζήτηση | αναδρομή στο αριστερό ή στο δεξί μισό |
| Αντίστροφη εκτύπωση | πρώτα αναδρομή, μετά printf |

### Σειρά εκτύπωσης
- `printf` **πριν** από την αναδρομική κλήση → τυπώνει κατεβαίνοντας (n, n−1, …).
- `printf` **μετά** από την κλήση → τυπώνει ανεβαίνοντας (…, n−1, n).

### Προσοχή
- Πάντα πρέπει να φτάνουμε στη **βάση** (π.χ. n−1, όχι n+1).
- Βαθιά αναδρομή → **stack overflow**.
- Η αναδρομή με δύο κλήσεις (Fibonacci) δίνει **εκθετικό** χρόνο.
@example
```c
void bin(int n) {               /* τυπώνει το n στο δυαδικό */
    if (n > 1) bin(n / 2);
    printf("%d", n % 2);
}
```
**bin(6):** bin(6) → bin(3) → bin(1) → τυπώνει 1 → επιστροφή, τυπώνει 3%2 = 1 → επιστροφή, τυπώνει 6%2 = 0 → **110** ✔.

Επειδή το printf βρίσκεται **μετά** την κλήση, τα ψηφία βγαίνουν από το πιο σημαντικό προς το λιγότερο σημαντικό — ακριβώς η «ανάγνωση από κάτω προς τα πάνω».
